# 🌤️ Weather App

A responsive and dynamic weather application built with **React.js** that fetches and displays real-time weather data for any city using the **OpenWeatherMap API**.

🔗 **Live Demo**: https://weather-app-xi-kohl-33.vercel.app/

---

## 🚀 Features

- 🌍 Search for current weather by city
- 🌡️ Displays temperature, weather conditions, humidity, and wind speed
- ⏱️ Real-time data using OpenWeatherMap API
- 📱 Fully responsive design
- ⚛️ Built using React functional components and hooks
- 🔄 Clean and dynamic UI updates

---

## 🛠️ Tech Stack

- **Frontend**: React.js, HTML5, CSS3
- **API**: OpenWeatherMap API
- **Deployment**: Vercel

---

## 📦 Installation & Setup

```bash
# Clone the repository
git clone https://github.com/your-username/weather-app.git
cd weather-app

# Install dependencies
npm install

# Create a .env file and add your OpenWeatherMap API key
REACT_APP_WEATHER_API_KEY=your_api_key_here

# Start the development server
npm start
